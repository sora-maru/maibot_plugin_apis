# API 聚合

关键词调用各类实用与娱乐 API，发送文字、图片、视频和语音。提供站点与接口编辑、批量测试、JSON 导入导出和本地缓存管理。

插件 ID：`github.sora-maru.apis`；版本：`1.0.7`；分类：**通用扩展**（`extension`）。

配置页的分组、字段名和填写说明均为中文。1.0.7 已适配 MaiBot 1.4.7、Plugin SDK 2.23.0 和 WebUI 1.10.7，同时保留旧版 MaiBot 1.3.16 的兼容性。已有配置、默认池、缓存和短关键词继续使用。

本版基于 Zhalslar 的 `astrbot_plugin_apis` **3.1.2** 移植。默认池已根据 **2026-11-10** 可读取的公开目录及文档重新生成，包含 **621 个 API 配置、6 个站点**，替换上游原有的 122 条预设。当前 395 条默认启用、226 条因密钥、维护或额外配置而默认停用。站点能访问不表示每个业务接口均已实测可用，详情见 [默认数据来源和完整清单](DEFAULT_DATA_SOURCES.md)。

## 💡 功能介绍

可以在面板动态添加免费或需要密钥的 API，为每个接口配置地址、参数、返回类型、解析规则及触发关键词。接口数量可以自行扩充，完整列表以 `/查看api` 和当前面板为准。接口名称保留来源，聊天触发词使用 1–6 个字符的短词，例如 `/翻译 你好 en`。

| 返回类型 | 当前预设数量 | 示例接口 |
|---|---:|---|
| 文字 | 515 | 冷雨枫林·多语言翻译、冷雨枫林·MD5加密、冷雨枫林·墨迹天气查询 |
| 图片 | 92 | 冷雨枫林·二维码生成、冷雨枫林·QQ头像获取、冷雨枫林·闲鱼作图 |
| 视频 | 11 | 冷雨枫林·视频大全及按文档配置的部分视频解析接口 |
| 音频 | 3 | 冷雨枫林·文字转语音及部分音频接口 |

站点池可管理访问密钥和请求头；API 池可启停和修改接口；本地数据页可查看和删除缓存。API 暂时失效时，可选择使用以前成功获取的本地数据兜底。

## 环境

截至 2026-11-20 核验的最新正式版为 [MaiBot 1.4.7](https://github.com/Mai-with-u/MaiBot/releases/tag/v1.4.7)，其 WebUI 为 1.10.7，Host 要求 Plugin SDK ≥2.23.0、Python ≥3.12。

| 验证组合 | MaiBot | SDK | QQ 适配器 |
|---|---|---|---|
| 当前版本 | 1.4.7 | 2.23.0 | [OneBot 适配器 1.3.1](https://github.com/Mai-with-u/MaiBot-SnowLuma-Adapter/releases/tag/v1.3.1) |
| 保留兼容 | 1.3.16 | 2.16.0 | SnowLuma 适配器 1.1.9 |

两个适配器版本的稳定 ID 都是 `maibot-team.snowluma-adapter`。旧的 1.1.9 清单只允许 MaiBot 1.3.x；升级到 MaiBot 1.4.7 时请同时使用适配器 1.3.1，按适配器迁移说明保留原连接配置。本插件继续复用现有 QQ 连接，无需再填写连接地址、端口或 Token。SnowLuma 客户端本身的版本与适配器版本分别维护，本次没有升级你的客户端或实例。

本插件自身需要 Python ≥3.11，运行新版 Host 时仍必须满足 Host 的 Python ≥3.12 要求。依赖为 `aiohttp`、`beautifulsoup4`，SQLite 来自 Python 标准库。清单兼容范围为 MaiBot 1.3.16–1.4.99、SDK 2.16.0–2.99.99；实际验证过的组合见上表和 `VALIDATION.md`。

### 从 1.0.6 升级到 1.0.7

替换插件源码或通过仓库更新后重载插件，再点管理页“重载页面”即可。此次只扩展 Host 兼容范围，并为消息 Hook 补充接管原因；**不需要重新导入或覆盖 API 池**。配置键、配置版本、站点密钥、关键词和数据目录保持兼容，621 条预设没有重新采集或改写。

## 安装

仓库：[sora-maru/maibot_plugin_apis](https://github.com/sora-maru/maibot_plugin_apis)。可使用 MaiBot 的仓库安装入口，填写该仓库地址；手动安装可下载源码 ZIP 后按下列步骤放入实例。

1. 解压安装包，将整个 `maibot_plugin_apis` 文件夹放进 MaiBot 实例的 `plugins/`。
2. 确保入口为 `plugins/maibot_plugin_apis/plugin.py`，文件夹内同时存在 `_manifest.json`，不要多套一层目录。
3. 重载插件或重启 MaiBot。如提示缺少 Python 包，用运行 MaiBot 的同一个环境执行：

   ```console
   python -m pip install -r plugins/maibot_plugin_apis/requirements.txt
   ```

4. 在 WebUI 的插件扩展页面中打开 **API 聚合管理**，检查站点池和 API 池。
5. 在 QQ 发送 `/查看api`；使用 `/查看api 冷雨枫林·二维码生成` 查看某接口的参数。随后可用 `/二维码 https://example.com` 等方式测试实际接口。

首次加载会将预设导入插件数据目录的 SQLite 数据库。之后修改、关闭或清空接口池都会保留，不会在每次重启时重新导入。删除初始化标记会再次启用初次导入逻辑，常规使用不需要手动修改。

### 已安装用户如何覆盖为最新默认数据

**更新源码不会自动覆盖你已经修改的数据库。** 更新到 1.0.4 后，重载插件和页面，打开 **站点池 → 右上角导入/导出下拉菜单 → 替换为最新内置默认数据**，再点 **备份并覆盖两个池**。

该操作先将当前 API 池和站点池完整备份到数据目录的 `pool_files/`，然后在一个数据库事务中替换为本版内置的 621 条配置、6 个站点。自己添加或修改的接口会被覆盖；同地址/同主机唯一匹配的站点密钥及请求头会合并保留。插件配置文件、本地缓存保留。请先停止测试并等待当前请求完成。完成窗口会显示备份文件名和路径。

普通“导入文件”会跳过同名接口，适合补充，不能代替完整覆盖。备份包含原有密钥等配置，请自行保存。更换域名的站点认证不能假定兼容，例如倾梦从旧域 .cn 的 `ckey` 迁到当前 .com 的 `key`，需根据新站要求重新获取或填写。详细操作和回退方式见 [默认数据说明](DEFAULT_DATA_SOURCES.md)。

## 短关键词（1.0.4）

聊天中无需输入网站名称，例如 `/翻译 你好 en`、`/二维码 内容`、`/转语音 你好`、`/猫眼票房`。621 条默认关键词均为 1–6 个字符，英文和数字也按字符计数；不区分大小写。同义接口分别使用 `二维码`、`二维码2` 等词，避免一次调用多个同类接口。默认启用接口优先使用无后缀关键词。

接口的管理名称和来源仍保留。完整对照见 [KEYWORDS.md](KEYWORDS.md)，`/查看api` 也会列出短词和对应接口名称。停用接口不会因缩短关键词而自动启用。

已安装用户替换源码并重载插件即可：插件会先备份，再只更新未改动的旧默认带来源触发词，保留参数、密钥、启用状态和自定义关键词。若某个新词与现有自定义规则冲突，则跳过该条，可在面板手动修改。此项更新无需使用“覆盖两个池”。

## 触发和参数

| 命令 | 说明 |
|---|---|
| `/查看api` | 列出接口名称 |
| `/查看api 接口名称` | 查看接口的参数及详细配置 |
| `/关键词 参数1 参数2` | 按接口正则规则触发，并用空格分隔参数 |
| `@机器人 关键词 参数` | 默认配置下的另一种触发方式 |

例如发送 `/二维码 https://example.com`，或引用一条包含所需文字的消息后发送接口关键词，插件会尝试从引用文字补足空参数。具体关键词以接口配置为准，修改关键词无需修改插件代码。

- 默认 **需要 `/` 前缀或 @机器人**。关闭配置 `trigger.need_prefix` 后，可直接发送面板中的完整关键词。
- `/查看api`、`/查看api列表`、`/api列表` 列出所有接口；后面加 API 名称可查看详情。`/apis_help` 也是帮助入口。
- 与上游相同，先用消息中第一个空白分隔的词匹配 API 正则，后续词依次作为参数。
- 参数先填空值，剩余参数再按配置顺序覆盖。仍然缺少参数时，先尝试引用消息的文字，否则使用发送者昵称。
- 仅保留本版上游实际实现的补全行为，不会自动把被 @ 的其他用户当作参数。
- 匹配成功后默认停止普通聊天处理，避免麦麦额外回复。可关闭 `trigger.consume_message` 让消息继续进入聊天流程；插件没有代替模型决定如何回复。
- 同一消息会去重，默认同一聊天同一用户有 2 秒冷却。请求使用有限并发，避免阻塞普通消息。

## 面板功能

站点池和 API 池都支持逐行勾选、表头全选当前页，以及 **启用所选、禁用所选、删除所选、清空选择**。翻页和排序保留选择；改变搜索或筛选条件后，不再符合条件的项目自动取消选择。批量操作旁显示所选总数，未选择项目时按钮禁用。

删除所选会先展示确认弹窗和名称列表；删除站点时显示关联 API 数量，确认后一起删除。

**手动启用/禁用站点时，该站点当前关联的 API 会一起启用/禁用**，列表开关及“启用所选/禁用所选”均生效。填好密钥后，启用站点即可一起启用其 API；站点原本已开启时，可先关再开，或勾选后点“启用所选”。这会覆盖关联 API 原先各自的开关状态，包括因维护或额外配置而停用的条目，使用前仍需确认接口要求。密钥、参数、有效性标记和其他站点的 API 不受影响。

仅保存密钥、名称或地址不会自动启停 API；启停会在一个数据库事务中保存，重载后保留。单独修改 API 开关仍可生效，下次手动切换所属站点时会再次跟随。独立子站点的 API 按更具体的地址归属，不随父站开关变化。

保留原站点池、API 池和本地数据三个分页，支持编辑请求参数、响应解析规则、触发正则、启用状态和使用范围，支持筛选、排序、批量删除、单项/批量测试、重复测试、暂停/取消及结果预览。

面板集成于 MaiBot WebUI，不需要为插件另开端口。页面使用独立视口布局；长表格、侧栏和弹窗正文分别滚动。所有弹窗均提供右上角及底部关闭按钮，也可用 Esc 或点击遮罩关闭。

### 修改站点地址和清理失效站点

- 修改站点地址后，会同步替换原先归属于该站点的 API 地址前缀，保留接口相对路径、查询参数及各 API 的其他配置。例如 `https://old.example/api/weather?city=北京` 在站点基础地址改为 `https://new.example/v2` 后变为 `https://new.example/v2/api/weather?city=北京`（原基础地址为 `https://old.example`）。修改站点名也会同步更新关联。
- 站点归属按协议、域名及路径边界匹配，存在子站点时优先匹配更具体的地址；修改父站不会改动独立子站所拥有的 API。
- 在站点池点击 **批量测试站点**，测试当前筛选结果中的全部站点；每行的“测试”按钮可单独测试该站点。测试其关联 API，汇总成功/失败数；没有 API 的站点则检查基础地址的响应。
- 全部失败只代表本次没有可用响应，也可能由网络、密钥、权限或参数造成，不能据此认定关站。
- 可点击 **选择本次全部失败站点**，或手动选择，随后点击 **删除选中站点及 API**。查看确认区列出的站点和 API 数量，确认后一次性删除站点及其当前关联 API。本地缓存保留。
- 普通站点列表的删除操作同样会删除其关联 API，仍需通过页面的待删除确认操作。数据库对站点及 API 的同步修改/删除使用同一事务。

站点的 `keys` 沿用原实现，会同时加入请求头和查询参数；请按 API 站点的要求填写。面板管理使用 MaiBot 已登录的 WebUI 权限，页面 API 不向其他插件公开。

### 配置需要密钥的站点

部分 API 站点需要注册账号或取得访问密钥。例如当前 [倾梦 API](https://api.317ak.com) 的目录声明使用查询参数 `key`；在 **站点池 → 编辑倾梦 → 密钥**中填写自己的 `key`，再按需求启用接口。枫雨二代使用的参数名可能是 `apikey`，糖豆子则按具体接口文档要求填写。请求头、参数和收费情况以站点当前文档为准；本包没有内置可用密钥。

API 的 `scope` 留空时允许所有人使用；填 QQ 号、群号或真实 MaiBot 会话 ID 可限制范围，填 `admin` 则仅允许配置 `trigger.admin_users` 中的 QQ 号。原 AstrBot 的会话标识不能直接当作 MaiBot 会话 ID 使用；导入旧规则时建议改为 QQ 号或群号。

JSON 导入会跳过同名条目。文件导入按块传输，浏览器文件上限 3 MiB；API/站点池可导出到插件数据目录下的 `pool_files/`，支持相对文件名及该目录内部路径。服务器导出目录为面板显示的路径，不能写到该目录以外。

API 响应会保存为本地数据；接口失败且启用 `data.use_local` 时，会从对应接口已有缓存中随机取一条。关闭 `data.save_data` 后不再保存新结果，已有缓存仍可按设置使用，不会为了清理临时结果而删除旧缓存。

文字响应中的真实回车换行以及字面量 `\r`、`\n`、`\r\n` 会转换为正常换行，用于聊天发送、测试预览及缓存显示。不会对中文执行整体 Unicode 转义解码。

## 配置

配置由 MaiBot SDK 生成，`config.example.toml` 只作参考。常用项：

| 项目 | 默认值 | 用途 |
|---|---|---|
| `plugin.enabled` | `true` | 启用插件 |
| `trigger.need_prefix` | `true` | 要求 `/` 或 @机器人 |
| `trigger.admin_users` | `[]` | 使用 `admin` 范围接口的 QQ 号 |
| `trigger.consume_message` | `true` | API 触发后停止普通聊天 |
| `trigger.cooldown_seconds` | `2` | 同一用户触发间隔 |
| `trigger.max_concurrent` | `4` | 同时执行的请求数量 |
| `data.save_data` | `true` | 保存新响应 |
| `data.use_local` | `true` | 失败时使用缓存 |
| `data.max_media_mb` | `8` | 响应和待发送媒体上限，1–11 MiB |

音视频以 Base64 内容跨进程发送，不要求 SnowLuma 能访问 MaiBot 的本地文件路径，也不附带引用回复。单份负载避免了 SDK 兼容参数重复携带媒体数据的问题。实际发送仍受 QQ、媒体格式和连接器支持影响。

## 📌 使用注意

- 部分免费接口会失效或更换域名、参数及返回格式。可先在面板测试，按站点当前文档修正，或寻找替代接口。
- 海外服务器及受限网络可能无法访问部分站点；请在运行 MaiBot 的服务器上检查网络。浏览器能访问不代表服务器也能访问。
- 密钥缺失、超时、限流或临时故障都可能导致测试失败。清理站点前请先核实，并按需导出 API 池和站点池作备份。
- 视频、音频独立发送，不附带引用消息。原 AstrBot 关于关闭引用开关和 Docker 映射媒体路径的操作不直接适用于本移植版；本版通过内容传输发送媒体。
- 首次使用建议先测试少量接口，确认密钥和网络。批量测试会请求选定范围内的实际接口，可能消耗站点配额。

## 数据与更新

数据库、初始化标记、缓存和导入导出文件保存在 Host 提供的 `data_dir` 中；临时路径来自 `runtime_dir`。替换源码时保留插件配置和该 ID 的数据目录。不要把运行时数据库、密钥或缓存提交到仓库。

独立移植版仓库为 [sora-maru/maibot_plugin_apis](https://github.com/sora-maru/maibot_plugin_apis)，清单中的更新来源、文档和问题反馈地址均指向该仓库。AstrBot 上游地址仅用于来源署名。

## 开发和验证

`plugin.py` 为消息和 SDK 入口；`api_aggregator/` 为请求、解析和存储核心；`page_controller.py` 保留面板业务，`web_gateway.py` 对接 MaiBot 私有页面 API。`pages/dashboard/` 为可编辑的前端源文件，`webui/index.html` 为自包含页面产物。

修改页面资源后运行 `python tools/build_webui.py`。功能测试可使用 `python -m pytest tests -q`，测试额外需要 `pytest` 和 `pytest-asyncio`。测试不会调用外部 API 或 QQ。验证详情及未验证事项见 `VALIDATION.md`。

上游版本移除了定时触发，本移植版未重新添加。保留上游 AGPL v3 许可证，来源和改动见 `THIRD_PARTY_NOTICES.md`。
